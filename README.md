# Chamados TI Prospera

Página estática para abrir, acompanhar e documentar os chamados de TI que ficam no Bitrix24.

Publicada em https://viniciusaugusto19.github.io/chamados-ti-prospera/

Não há servidor nem segredo neste repositório: a ligação com o Bitrix é feita no navegador de quem usa, com o webhook de cada pessoa, que fica guardado só na máquina dela.
